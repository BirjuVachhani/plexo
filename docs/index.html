Link bonding

Every interface pulls its own chunk range. Add a tethered phone mid-download and it joins the file in progress.

Per-link telemetry

Live speed, share, latency and bytes moved for each connection, so you can see which one is holding you back.

Resume anywhere

Drop a link, close the lid, change networks. Chunk state is on disk, so downloads pick up where they stopped.

Verified on completion

Merged output is checksummed before Plexo hands the file over. One stream in, one intact file out.
